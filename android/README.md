# School Note

Локальное Android-приложение с русским и казахским интерфейсом. Android 8.0+.
Несколько классов, ученики, предметы, датированные оценки и посещаемость.
Шкалы: 5, 10, 12, 100 или свой максимум от 2 до 100. Оценки от 1 до максимума.
Старая оценка сохраняет исходную шкалу. Средний балл вычисляется как среднее
долей value/max_value, умноженное на текущий максимум.

Данные хранятся в SQLite в закрытом каталоге приложения. Сетевых разрешений,
аналитики и внешних библиотек нет. В настройках можно сохранить и восстановить
резервную копию JSON через системный выбор файла. Восстановление проверяется и
выполняется одной транзакцией; ошибочный файл не удаляет текущие данные.

## Сборка

Нужны JDK 17+, Python 3 и официальный Android SDK:
platforms;android-35, build-tools;35.0.0.

Задайте JAVA_HOME и ANDROID_SDK_ROOT, затем запустите `python build.py`.
Скрипт предназначен для Windows и использует aapt2, javac, D8, zipalign,
apksigner. Он создаёт подписанный APK в build/release/School-Note-1.1.1.apk.
Ключ подписи создаётся в соседней папке signing; храните его для обновлений.
Приложение не собирается в debug-режиме.

`python build.py --tests` также создаёт APK инструментальных проверок.
Установите оба APK на тестовый эмулятор и выполните:
`adb shell am instrument -w kz.school.journal.tests/kz.school.journal.JournalTests`.
Проверки используют тестовые данные и очищают журнал на тестовом устройстве.
